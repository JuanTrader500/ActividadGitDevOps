## Explicacion de los comandos basicos de git 

init: ES un comando para inicializar el proyecto en local desde el bash

add: Es un comando para "guardar los cambios" en local para que despues se pueda hacer un commit. sin esto git no reconose o noo guarda los cabios.

commit: Este comando guarda los cambios que se hicieron previamente en el git add. SOLO los archivos que entraron en el git add.

push: Este comando es el que se encarga de subir los cambios aprobados en el commit con la nota del commit. este push se encarga de guardar los cambios en la rama a la que se ponga ya sea el main o X_branch o a la rama remota.

diff: Muesta la diferencia de lo que tiene un archivo nuevo o editado. (Es una comparacion de lo que esta ahora y o que estaba antes)

log: Como lo dice el nombre este comando es un historial de commits que se han echo en el repo desde el mas reciente hasta el mas antiguo.
